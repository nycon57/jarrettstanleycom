# Icons

The site uses the same icon set and rules as the product (TrueToneAI-App `docs/DESIGN_SYSTEM.md`, "Icons").

## The set

- **Interface icons:** IconMCP outline, vendored at `src/components/icons/iconmcp/icons.tsx`. Generated by `scripts/icons/vendor-iconmcp.mjs` from `vendor/iconmcp/`; never edit it by hand.
- **Brand logos:** `src/components/icons/brands.tsx` (Simple Icons, plus CoreUI Brands for LinkedIn and MDI for Google Business Profile).
- No Lucide, Heroicons, Tabler or react-icons. A shadcn component that arrives with a `lucide-react` import gets its icons swapped before it merges.

To add an icon: `node scripts/icons/search-iconmcp.mjs <words>`, add the name to `vendor/iconmcp/picked.json`, run `node scripts/icons/vendor-iconmcp.mjs`, and import `Icon<Name>` from `@/components/icons/iconmcp/icons`.

IconMCP draws on a 16-unit grid, so `strokeWidth` is about half of Lucide's: Lucide 2 reads like IconMCP 1 (the default).

## The rules

**Icons are bare. No icon chips.** No tinted square, disc or gradient tile behind a glyph. The glyph sits beside its words.

Colour says what a thing is, and never decorates it:

| The icon stands for | Colour |
| --- | --- |
| A channel or platform | its own accent |
| A status (passed, warning, error) | the status colour |
| Anything else | `text-(--hp-muted)` |

1. No icon in a section header. The heading already names the section.
2. Rows: `size-5` glyph (`size-4` in a dense row). Tiles: `size-6` above the label. Empty states: `size-10`, no disc.
3. These are not chips, so they keep their fill: avatars and initials, numbered step markers, logos, timeline and diagram nodes, and icon-only buttons and links.

`tests/design/no-icon-chips.test.ts` fails on a new chip. A real non-chip goes in its `ALLOWLIST` with a reason.
